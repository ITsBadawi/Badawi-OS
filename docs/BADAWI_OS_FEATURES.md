# Badawi OS — قائمة الميزات المتفق عليها

**نوع البرنامج:** تطبيق مكتبي لنظام Windows، وليس نظام تشغيل بديلاً عن Windows.  
**الفكرة:** مركز عمل شخصي مدعوم بالذكاء الاصطناعي لإدارة المهام والمشاريع والملفات والنسخ الاحتياطية والأتمتة من مكان واحد.

## 1. الواجهة الرئيسية (Smart Dashboard)
- لوحة ذكية تعرض أولويات اليوم، المهام، المشاريع التي تحتاج اهتماماً، التنبيهات وحالة الأتمتة.
- يتغير المحتوى حسب وضع العمل، مع إمكانية تثبيت العناصر المهمة؛ هيكل الواجهة يبقى منظماً وثابتاً.
- تصميم بسيط، مع **الوضع الداكن والفاتح** ودعم **العربية والإنكليزية**.
- مساعد AI جانبي من أي صفحة، ومحادثة كاملة، وشريط أوامر سريع (مثل `Ctrl + K`).

## 2. المساعد الذكي (AI Brain)
- دعم **Gemini وOpenAI منذ البداية**، وإمكانية اختيار المزود والنموذج من الإعدادات.
- يفهم أوامرك باللغة الطبيعية ويبحث عن المعلومات المرتبطة بالطلب قبل الإجابة.
- ذاكرة لتفضيلاتك، قراراتك، سياق المشاريع وسجل العمل، مع إمكانية مراجعتها وتصحيحها.
- البحث في محتويات المشاريع والملفات المسموح بها وتلخيصها والإجابة عنها.
- يقترح الخطط والأولويات وينفذ العمليات المصرح بها باستخدام أدوات محددة، وليس وصولاً مفتوحاً للحاسوب.
- يعرض استخدام الـAPI والتكلفة التقديرية، ولا يرسل بياناتك لمزود آخر تلقائياً دون سياسة تسمح بذلك.

## 3. المهام والجدول (Tasks & Calendar)
- إنشاء وتعديل وتصنيف المهام: الأولوية، الحالة، الموعد، الوصف، والمشروع المرتبط.
- طرق عرض **List / Calendar / Kanban**.
- ترتيب جدول اليوم والأسبوع وإعادة جدولة المهام المرنة بالـAI.
- تذكيرات ومهام متكررة ومراجعة يومية للمهام المتأخرة.
- المواعيد النهائية الثابتة لا تتغير تلقائياً دون موافقتك.

## 4. إدارة المشاريع البرمجية (Project Manager)
- إنشاء مشروع جديد، أو استيراد مشروع محلي، أو استنساخ مشروع من GitHub.
- لكل مشروع: اسم ومعرّف ثابت، مسار محلي، وصف، تقنيات، مستودعات Git، فروع، خدمات نشر، مهام وملفات مرتبطة.
- فحص حالة Git المحلي والتغييرات غير المحفوظة أو غير المرفوعة، ومقارنتها مع GitHub.
- متابعة حالة النشر على **Vercel / Railway** عند إضافة تكاملاتهما.
- معرفة آخر نشاط، المشاكل الظاهرة، المهام المتبقية، وحالة النسخ الاحتياطية.
- قراءة الكود وتحليله والإجابة عن أسئلة تخصه، **من دون كتابة الكود أو تعديله في الإصدار الحالي**.
- عمليات Git مثل Commit/Push تكون بعد معاينة وموافقة صريحة، مع التحقق من النتيجة.

## 5. إدارة الملفات (Files Manager)
- إنشاء **Workspace** بمسار تختاره أنت، مع فصل مجلد **Files** عن مجلد **Projects**.
- قسم Files يعرض ويدير فقط ملفات العمل داخل المسار المسموح به؛ لا يتصفح بقية الحاسوب تلقائياً.
- بحث بالاسم والنوع والمحتوى المفهرس، وتنظيم الملفات وإنشاء المجلدات وتصنيفها.
- يقدر الـAI يفهم أن «ملفات التصميم» في Files وأن «الكود» في Projects، عبر سجل مركزي وفهرس محلي.
- ربط ملفات التصاميم والمستندات بالمشروع برابط منطقي من دون تكرارها.
- النقل أو إعادة التسمية أو التعديل المؤثر يحتاج معاينة وصلاحية مناسبة.
- مجلد **Inbox** اختياري لاستقبال الملفات الجديدة وتصنيفها.

## 6. النسخ الاحتياطية (Google Drive Backup)
- **جميع النسخ الاحتياطية الدائمة على Google Drive فقط**؛ لا توجد وجهة نسخ احتياطي دائمة محلية في الخطة.
- نسخ يدوي أو مجدول لكل مشروع أو مجلد عمل تختاره، مع تحديد ما يُنسخ وما يُستثنى.
- نسخ بإصدارات (Snapshots)، وتجنب إعادة رفع البيانات غير المتغيرة قدر الإمكان.
- ضغط وتشفير وحماية بيانات الاعتماد والملفات الحساسة.
- سياسات احتفاظ وحذف تحددها أنت، مع حماية النسخ السليمة من الحذف الخطأ.
- عرض تاريخ النسخ وحالتها، والتحقق من السلامة، واستعادة ملف أو مجلد أو مشروع كامل.
- متابعة السعة المتاحة وتذكيرات بانتهاء باقة Google Drive عند تحديد تاريخ انتهائها.
- ملفات تجهيز مؤقتة محلياً مسموحة أثناء الرفع، ولكن ليست نسخاً احتياطية دائمة.

## 7. الأتمتة (Automation Engine)
- يعمل **محلياً على Windows باستخدام محرك خفيف (Node.js)**؛ **بدون n8n أو Docker أو سيرفر مدفوع** في البداية.
- إنشاء قواعد من واجهة البرنامج أو بطلب طبيعي للـAI؛ وعرض القاعدة قبل تفعيلها.
- تشغيل الأتمتة حسب الوقت أو حدث أو شرط أو أمر يدوي.
- أمثلة: تذكير، إعداد ملخص يومي، فحص GitHub، فحص ملفات جديدة، نسخ Google Drive المجدول.
- سجل عمليات دائم، وإعادة محاولات آمنة، وإشعارات عند الفشل أو الحاجة لموافقة.
- عند إطفاء الحاسوب لا تعمل الأتمتة المحلية؛ تُعالج المواعيد الفائتة عند تشغيله بحسب نوع المهمة.
- الـAI يصمم القاعدة ويفسر النتائج؛ المحرك البرمجي ينفذها ويتحقق منها.

## 8. التحكم بالمحرك وحماية أداء الألعاب
- **Running:** التشغيل الطبيعي لجميع الخدمات.
- **Paused:** إيقاف الأعمال الخلفية مؤقتاً.
- **Gaming Mode:** تعليق الفهرسة والنسخ والرفع والتحليل والـAI بالخلفية لتخفيف استهلاك الموارد والمحافظة على FPS.
- **Stopped:** إيقاف محرك الخلفية بالكامل مع بقاء واجهة التحكم متاحة.
- تفعيل وضع الألعاب يدوياً أو تلقائياً عند فتح ألعاب تحددها أنت.
- استئناف العمل عند انتهاء اللعب، مع إيقاف العمليات الحساسة عند نقطة آمنة دون إفساد الملفات.

## 9. الصلاحيات والأمان (Hybrid Agent)
- أربع سياسات للأدوات: **قراءة فقط، تنفيذ تلقائي، يتطلب موافقة، ممنوع**.
- العمليات الروتينية الآمنة تعمل تلقائياً ضمن حدود محددة؛ الحذف وتغيير الكود والنشر والإجراءات الحساسة تحتاج موافقة أو تظل ممنوعة.
- لا يستطيع الـAI توسيع صلاحياته أو تشغيل أوامر Terminal عامة بلا قيود.
- السماح بالوصول فقط إلى مسارات Workspace والحسابات والمشاريع التي تربطها صراحة.
- حفظ مفاتيح الـAPI والرموز بصورة محمية، وسجل تدقيق لما فعله النظام.
- معاينة قبل العمليات المؤثرة، وتأكيد نجاح العمليات من مصادرها الحقيقية، لا بمجرد كلام الـAI.

## 10. التحقق والتقارير (Verification & Analytics)
- ربط كل مهمة بمعايير إنجاز، وفحص الأدلة المتاحة مثل Git Commits والاختبارات وحالة النشر.
- توضيح الفرق بين «أنجزت»، و«يحتاج مراجعة»، و«تعذر التحقق».
- تقارير عن تقدم المشاريع، المهام المتأخرة، النشاط، الأتمتة، النسخ الاحتياطية والتنبيهات المهمة.
- عرض تاريخ آخر تحقق ومصدر المعلومة حتى لا تبدو البيانات القديمة كأنها حالة لحظية.

## 11. التكاملات
- **Gemini + OpenAI:** أساسيان من الإصدار الأول.
- **GitHub:** ربط المستودعات وفحص حالتها، مع عمليات رفع خاضعة للموافقة.
- **Google Drive:** الوجهة الوحيدة للنسخ الاحتياطية الدائمة.
- **Vercel وRailway:** متابعة النشر والحالة، ضمن مراحل التطوير التالية.
- بنية تكاملات قابلة للتوسع بخدمات أخرى لاحقاً.

## خارج الخطة الحالية
- **لا توجد ميزة حظر مشتتات أو إجبار على التركيز** ولا Soft/Strict/Deep Focus ولا Learn to Unlock.
- **لا يوجد AI Coding Agent** يكتب أو يعدل كود المشاريع حالياً؛ يمكن إضافته مستقبلاً.
- لا نحتاج تشغيل الأتمتة والحاسوب مطفأ، ولا بنية Cloud Server في الإصدار الأول.
- لا نبدأ بمحرر Workflows معقد شبيه بـn8n؛ نبدأ بالقواعد والأدوات المطلوبة فعلاً.

---

**هدف النسخة الأولى:** برنامج Windows مستقر ومفيد يومياً، يجمع إدارة العمل والمشاريع والملفات والمساعد الذكي والأتمتة والنسخ إلى Google Drive، مع إمكانات توسعة لاحقة بدون إعادة بناء جوهر النظام.
