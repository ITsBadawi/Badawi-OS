Badawi OS 0.4.1 — نسخة قبول محلية

فكّ ملف ZIP كاملاً، ثم افتح Badawi OS.exe مع إبقاء المجلدات المرافقة. هذا الملف لا يحتوي قاعدة بياناتك أو مفاتيح حساباتك أو مفتاح استرداد النسخ. حزمة 0.3.0 السابقة محفوظة للرجوع إليها.

1) أنشئ Workspace من صفحة «الملفات» بمسار تختاره. سيُفصل Files عن Projects، ويمكنك استخدام Inbox اختياري. فهرس المحتوى والكتالوج والروابط المنطقية لا يفتشان بقية الجهاز تلقائياً.
2) في «الإعدادات» اختر العربية أو الإنجليزية والمظهر، واضبط مزود AI والنموذج. يدعم Gemini ومفتاح OpenAI و«المتابعة باستخدام ChatGPT» بحساب الاشتراك المؤهل. ابدأ المحرك بزر «تشغيل» قبل الفحص أو المحادثة.
3) في «المشاريع» اربط مستودع GitHub أو استنسخ مشروعاً تجريبياً. حدد ملفات Commit بنفسك أو راجع اقتراح Badawi، ثم وافق على Commit المحلي. الرفع إلى GitHub يحتاج معاينة وموافقة منفصلتين ويتحقق التطبيق من رقم Commit البعيد. لا يستطيع المساعد تعديل كود المشروع أو الرفع بنفسه.
4) «المهام» تعرض القائمة والتقويم ولوحة Kanban، مع التكرار والتذكيرات ومعايير الإنجاز. نجاح فحص GitHub أو النشر وحده لا يحل محل مراجعتك لمعنى المهمة.
5) النسخ الاحتياطية الدائمة على Google Drive فقط. اختر المصادر والاستثناءات، واحتفظ بمفتاح الاسترداد خارج Drive. النسخ الجديدة المضغوطة تُستعاد بهذا الإصدار الأحدث، وليس بإصدار 0.3.0.
6) المحرك يبدأ «متوقفاً» بعد كل تشغيل. «إيقاف مؤقت» و«وضع الألعاب» يوقفان الأعمال الخلفية المناسبة. وضع الألعاب التلقائي يعتمد أسماء البرامج التنفيذية التي تضيفها بنفسك.

اختبارات النسخة الحالية: 220 اختباراً برمجياً ناجحاً، وفحوص فعلية للتطبيق شملت الملفات والمهام والأتمتة والنسخ والمحادثة وGit. نجح تسجيل ChatGPT وطلب حقيقي من الاشتراك، ثم طلب حقيقي آخر خطّط مهاماً وهمية وغيّر موعد مهمة مرنة بعد مراجعتها مع الحفاظ على موعد ثابت. نجح استنساخ وCommit وPush على مستودعين خاصين اصطناعيين، وكذلك قراءة فحص GitHub Actions الحقيقي لمهمة تجريبية. لم تُرفع ملفات مشاريعك الحقيقية.

نجح فحص نشر Vercel الحقيقي من داخل نسخة Badawi OS المعزولة، وحُذف الرمز المؤقت بعد الاختبار. اكتمل التدقيق المحلي للنسخ المجدولة والاحتفاظ والاستعادة والأتمتة. اجتازت بياناتك الفعلية تجربة توافق مؤقتة، ثم فُتح 0.4.1 ببياناتك وحساب ChatGPT المتصل، وحُدّث اختصار سطح المكتب وقائمة ابدأ. يبدأ المحرك متوقفاً. النسخة السابقة ما زالت متاحة. اختبار Railway مؤجّل بطلبك، ولا يوجد مفتاح OpenAI API معدّ لإجراء اختباره المباشر؛ لذلك لا ندّعي اكتمال كل فحوص الحسابات الحقيقية.

النسخة غير موقّعة رقمياً، وقد يعرض Windows تحذيراً عند فتحها. التفاصيل والاختبارات في README.md وdocs/FEATURE-PARITY-WORKING-STATUS.md.
